# OmniFlow ♾️✨
### Smart Universal Class Timetable, Schedule Planner & Voice Reminder App (PWA)

**OmniFlow** is a modern, responsive, and feature-rich Progressive Web Application (PWA) designed for students, teachers, and professionals across all academic disciplines and institutions. It features real-time class tracking, custom time slot configuration, voice notifications (Text-To-Speech), task management, subject progress analytics, dark/light themes, and seamless offline functionality.

---

## 🌟 Key Features

- **📱 Full PWA Support & Offline Access**: Installable directly on Android, iOS, Windows, and macOS as a standalone native-feeling app with offline caching.
- **🔊 Voice & Chime Notifications**: Integrated Web Audio API chimes and Web Speech API (TTS) voice announcements in both English and Myanmar languages.
- **📅 Interactive Timetable**: Customizable daily/weekly schedules, room numbers, teacher names, color codes, and subject notes.
- **⚡ Real-Time Active Class Bar**: High-visibility top header highlighting current ongoing class, time remaining progress bar, and next upcoming activity.
- **✅ Task & Assignment Manager**: Organizes homework, exams, and projects filtered by subject and urgency deadlines.
- **📊 Subject Progress Analytics**: Visual attendance trackers, completion rates, and weekly workload breakdown.
- **🎨 Modern Responsive UI**: Desktop, Laptop, Tablet, and Mobile viewport preview toggles with dark slate & ambient light styling.
- **☁️ Cloud & Local Storage**: Firebase Firestore database synchronization with local persistence fallback.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `bun`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/omniflow.git
   cd omniflow
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Animation**: Motion (Framer Motion)
- **Audio & Speech**: Web Audio API & Web Speech API
- **Persistence**: Firebase Firestore & LocalStorage
- **PWA Capabilities**: Web App Manifest & Service Worker
